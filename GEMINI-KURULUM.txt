GEMINI BAGLANTISI - YALNIZCA DEGISEN DOSYALAR
================================================

1) Bu ZIP dosyasini MCP-Veri-Asistani klasorunun icine cikart.
   Windows dosyalari degistirmek isterse onayla.

2) VS Code'da backend/.env dosyasini ac.
   Asagidaki iki satiri ekle:

   GEMINI_API_KEY=BURAYA_KENDI_ANAHTARINI_YAPISTIR
   GEMINI_MODEL=gemini-3.1-flash-lite

   Anahtarin basinda/sonunda tirnak veya bosluk olmasin.
   Anahtari kimseyle paylasma ve GitHub'a yukleme.

3) Backend terminalini kapatip yeni terminal ac:

   cd C:\Users\ceyda\Downloads\MCP-Veri-Asistani\backend
   npm run dev

4) Frontend zaten aciksa sayfayi yenile. Acik degilse proje kokunde:

   cd C:\Users\ceyda\Downloads\MCP-Veri-Asistani
   npm run dev

5) http://localhost:3000 adresini ac.
   Sag ustte "Gemini modu" yazmali.

6) Gercek yapay zeka testi icin sunu sor:

   Tamamlanmis siparislerin ortalama tutarini ve en yuksek tutarini goster.

   Cevabin altinda "Gemini" ve "MCP" etiketleri gorunurse baglanti tamamdir.

Not: Ucretsiz Gemini kotasi dolarsa, uygulama tanidigi ornek sorularda
cevrimdisi kural motoruna otomatik olarak geri doner.
